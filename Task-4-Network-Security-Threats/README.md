# Task 4 – Common Network Security Threats

## Objective

The objective of this task is to study common network security threats, understand how they work, analyze their impact, and identify suitable mitigation techniques.

## Threats Covered

- Denial-of-Service (DoS)
- Distributed Denial-of-Service (DDoS)
- Man-in-the-Middle (MITM)
- IP Spoofing
- DNS Poisoning / DNS Spoofing

## Report Contents

The report covers:

- How each attack works
- Real-world examples
- Potential impact
- Recommended mitigation techniques
- Comparison of the threats
- Key recommendations for network administrators

## Deliverable

`network_security_threats_report.md`

## Resources Used

- NIST cybersecurity publications
- CISA cybersecurity guidance
- Security research and documentation

## Ethical Considerations

This task is a research-based cybersecurity activity. No unauthorized scanning, exploitation, interception, or attack activity was performed against real systems or networks.

## Conclusion

This report demonstrates an understanding of common network security threats and the security controls that can be used to reduce their risks.
